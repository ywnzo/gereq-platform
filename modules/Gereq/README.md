# GEREQ module

Ticketing + Security products (ported from GEREQ.cz) for the GEREQ platform.

- Admin: `/admin/gereq/ticketing`, `/admin/gereq/security` (permission `gereq.manage`, privileged admins only)
- Embed: `/js/gereq-tickets.js`, `/js/gereq-security.js`, `/js/gereq-monitor.js`
- Runtime APIs: `/tickets/api/*`, `/security/api/*`
- Authenticated API: `/api/v1/gereq/*`

See `docs/modules/gereq.md`.
